Bonsai 8 · quick guide

Two songs.
Eight stems.

These physical controls require Bonsai 8 0.4. The current release is a test candidate: eight-stem playback with effects, USB audio and recording still needs hardware testing.

01 / Pick a deckTap FUNCTION to switch between Deck A and Deck B. Controls affect the selected deck; the other deck keeps playing.

02 / Pick any songHold FUNCTION and move the side wheel to browse any occupied song slot. Release FUNCTION, then tap PLAY to play or pause that deck. The site’s Load A / Load B buttons also cue any loaded song.

03 / Mix the stemsEach fader controls one stem’s volume. Tap its track button to mute it. Hold a track button to solo temporarily. Move a fader through its saved level after switching decks to pick it up.

04 / Speed and pitchMove the wheel without FUNCTION to change the selected deck’s speed and pitch together. Volume buttons control the overall mix. There is no automatic beat matching, key matching or independent pitch shifting.

05 / Shape a stemHold FUNCTION and that stem’s track button. Move its fader to set the effect amount; use the wheel to select Off, Filter, Echo or Reverb. Release the buttons when finished. Effect settings are saved.

06 / Effect characterFilter softens the high frequencies. Echo uses a fixed 250 ms delay. Echo and reverb use dark, mono effect audio at 4 kHz; the dry signal stays stereo. They are not tempo-synced studio effects.

07 / Record on the playerHold FUNCTION and both volume buttons for one second to start recording Deck A + Deck B. Use the same gesture to stop. No computer is needed. The recording becomes one stereo track in an empty song slot.

08 / Finish savingAfter stopping recording, pause both decks to save. If both are playing, hold FUNCTION and tap PLAY. If only one is playing, select it and tap PLAY; check both are paused. FUNCTION + PLAY would start both when either is paused. Keep the player powered on until saving finishes.

On your player lists all loaded songs. Export a saved recording as a WAV, or a multitrack song as a ZIP. Uploads, exports and deletions pause both decks. Delete names only the selected slot; other songs stay intact.

When connected, the model, lights, faders and mix settings follow the physical player. Change its mix on the device. The site can load songs into either deck; its browser mixer does not remotely change physical volume or pitch.

For browser-only playback, drop a song and choose Separate into 4 stems, import existing stems, or try the demo. Drag the faders and use mute or solo. Separation runs locally and can take several minutes; keep the tab open or choose Cancel.

About

SP–1, reimagined
for the browser.

A reference-based 3D recreation of the Teenage Engineering SP–1. Dimensions and finish are approximate; this is not a factory CAD model or official firmware emulator.

Built with Three.js, Web Audio, ONNX Runtime, and Meta’s HT-Demucs model. Music is processed on your own device.

Hardware polling follows the Solderless device monitor. Visual references: device photographs, the original user guide, and product photographs.

Model: StemSplit’s HT-Demucs ONNX export. Licenses and source credits ↗

Not affiliated with Teenage Engineering. Live monitoring follows physical diagnostics. Song management and firmware installation are explicit actions. Loading a song pauses only the chosen deck; file transfers pause both decks. USB audio and mirroring require compatible custom firmware. Browser timing and speaker output may differ by a small delay.
